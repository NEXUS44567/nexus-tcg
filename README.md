# NEXUS TCG — site en ligne

Version en lecture seule de NEXUS TCG, publiée avec GitHub Pages : catalogues One Piece TCG et Pokémon TCG, Pokédex, comparaison et analyse d'équipe. Les prix affichés sont des données de démonstration fictives.
